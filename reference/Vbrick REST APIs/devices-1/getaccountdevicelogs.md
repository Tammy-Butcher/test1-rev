  Get a list of logs for a specific account's devices. <p>The actionName
  parameter represents the type of device log entry. For example,  DME
  actionName parameters are equivalent to the Activity entry within the DME
  Server Log display. (Which can be found at the DME Management > Actions > View
  Logs).</p><p>For use with the API, the parameter should be formatted in Pascal
  case. This applies to LDAP devices as well.  A few of the more common
  activities are displayed in the dropdown below.</p>
