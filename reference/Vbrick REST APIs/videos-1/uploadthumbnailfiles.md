excerpt: >-
  Uploads an alternate image to be used as a thumbnail for a specified video.
  Vbrick auto-generates a default thumbnail if you do not upload one of your
  choice. Note that if you replace Vbrick’s auto-generated thumbnail with one
  that you upload it will be deleted and may <em>not</em> be recovered.
