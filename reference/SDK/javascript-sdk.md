The **Rev SDK** is a **JavaScript** library that enables you to embed Webcasts and VODs on your website, content management site, virtual event platform, 3rd party portal, or any other web-based application using JavaScript code. Currently, the Rev SDK only supports interaction with the webcast video player.  In future releases, we plan to add support for additional webcast features including slides, chats, Q&A, and polls. More authentication methods are also planned.

## Getting Started

The **Rev SDK** is designed to get developers quickly up-and-running with detailed documentation and a sample application.  This means you can easily start to embed your Rev videos and webcasts seamlessly wherever they are needed – for internal or external audiences, on **Public **or **Private **websites.  

### Authentication

The SDK currently supports embedding of **Public** webcasts and videos.  **Private** webcasts are supported using [OAuth2 Authorization](ref:authorize) authentication.  JWT authentication will be supported in an upcoming release.
