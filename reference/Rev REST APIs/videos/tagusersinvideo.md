title: Tag Users in Video
excerpt: >-
  This endpoint sends a video for Facial Recognition and tags the user accounts
  recognized in the video. The Vbrick account must have [Facial
  Recognition](/docs/facial-recognition) activated and the user account must be
  enabled for recognition (i.e., profile not opted out and have a recognizable
  profile picture uploaded). You must also have the [Vbrick Video IQ
  User](/docs/roles-and-permissions#granular-roles-and-permissions) role to use
  this function.
