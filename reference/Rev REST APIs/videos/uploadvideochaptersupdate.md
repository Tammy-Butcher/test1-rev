title: Update Video Chapters
excerpt: >-
  This endpoint uploads and edits a chapter(s) for a specified video. Using the
  <strong>PUT</strong> method (editing) chapters <em>replaces</em> an existing
  chapter if it is a duplicate timestamp. <p>New chapters are created if the
  chapter does not exist at the specified timestamp. There can be multiple
  chapter titles and start times.</p><p>The endpoint requires the user have edit
  rights to the video.</p>
