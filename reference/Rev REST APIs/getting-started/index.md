Rev API is the primary means for developers to access, create and modify resources in Rev. Apps can read and write to the resources and mirror some of the most popular features available in Rev Web Portal such as uploading and editing videos, creating, editing, and starting webcasts, adding and removing users and groups, viewing reports and much more using the Rev API. Depending on your app’s use case, you can choose from our various APIs and implement the features accordingly.

## What's Possible with Rev APIs?

Vbrick invests significant engineering resources to ensure the Rev API suite is able to meet as many of your use cases as possible. Some of the most common use cases for using the Rev API include:

* Uploading videos and metadata from third party systems
* Searching and discovering videos including speech search
* Embedding Rev videos on third party systems
* Scheduling and managing webcasts
* Recording webcasts and live videos
* Managing users, groups, devices, and other administrative related functions

## Availability

All APIs documented here are available with **Rev Cloud** accounts. However, they all may not be available with certain versions of **On-Premise** versions of Rev.
