## :star2: **New**

### LMS Export Support

Users that have the Account Admin, Media Admin, or LMS Export role now have the ability to use the [Download Video LMS SCORM Package](ref:downloadvideolmsscormpackage) endpoint. This endpoint downloads a SCORM 2004 package for use in Learning Management Systems (LMS). Packages can be configured with completion thresholds, forward-seeking restrictions, and continue-watching settings tailored to the LMS.
