Rev's **Generative AI Tools** includes the Vbrick **Video Assistant** chat interface which can be used to ask questions about a video to glean quick insights and a summary about its content. Also featured is the **Video Metadata Generation** tool that uses the **transcript summary** of your videos to generate automated metadata such as **descriptions**, **tags**, **titles** , and **chaptering** on request.  This enhances your content's searchability and context and makes your workflow more efficient at the same time.

<Image align="center" border={false} src="https://files.readme.io/af485f898faf6be58211629b4bc507e9b838573f3d9d9e793876ed6a9631e957-enableGenAISettings.png" />

Here are some specific examples of what you can do using Rev's **Generative AI Tools**:

* [Vbrick Video Assistant](doc:vbrick-assistant) - Allows you to use the **Video Assistant** chat interface to ask questions about a video.  Gain valuable insights and highlights quickly as well as speaker information and content-related inquiries. The video must have an English transcript for this feature to function correctly.
* [Video Metadata Generation](doc:video-metadata-generation) - If you have [Rev IQ credits](doc:rev-license-types-and-add-ons#rev-iq-credits) available _and_ the video has an English transcript, you can use Vbrick's generative AI features to summarize its transcript to [automatically generate its metadata](doc:video-title-description-and-tags#use-vbrick-generative-ai-for-automatic-video-metadata-generation) for you.
* [Enhanced Multimedia Analysis](doc:enhanced-multimedia-analysis) - When this is enabled, chapter images and the video thumbnail are included for analysis in metadata generation. The video assistant includes chapter images, the video thumbnail, and supplemental files in PNG, JPEG, GIF and PDF format(s) in addition to the video transcript. This feature requires additional [Rev IQ credits](doc:rev-license-types-and-add-ons#rev-iq-credits).
