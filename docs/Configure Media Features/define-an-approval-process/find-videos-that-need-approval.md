There are three different ways to find videos that need your approval if you are part of a content Approval Process.

* Email / Notification
* Media Menu Options
* Approval Process Queue

## Email / Notifications for Video Approval

If you are an **Approver** in an **Approval Process** or step, each time a video is submitted for approval, you receive an email (if not suppressed). A URL links you to the video that is **Pending Approval**.

<Image align="center" src="https://files.readme.io/60a0700-suppressEmailChecked.png" />

> 📘 Note
>
> If the **Suppress Email** control is checked next to the Approver, that account(s) will *not* receive pending *approval* emails.
>
> *Rejection* emails are still sent. This function may be set at all approval stages.

Each time a video is submitted, you receive a [Notification](doc:notifications) update.  Clicking this notification also takes you to the video to review the submission.

<Image align="center" src="https://files.readme.io/e8db16f-approverNotification.png" />

## Media Menu Options

A **Pending Approval** button is also visible under **Media** > **All Videos** and **My Videos** menu options when you have videos that have been submitted and are waiting for your approval. 

<Image align="center" src="https://files.readme.io/95481b5-pendingApprovalButton.png" />

The button displays a numerical value indicating the number of videos in your approval queue. Clicking the button takes you to a tiled gallery of videos to review.

<Image align="center" src="https://files.readme.io/c684b45-approvalRequested.png" />

## The Approval Process Queue

The **Approval Process Queue** displays an overview of all videos that are currently part of an approval process step. Admins access it through the **Admin > Media Settings > Approval Process Queue** menu option.

<Image alt="Clicking the title of a video allows you to review it" align="center" src="https://files.readme.io/f349c47-approvalProcessQueue.png">
  Clicking the title of a video allows you to review it
</Image>

It displays the following information about each video:

* Title
* Owner (that submitted the video for approval)
* Approval Process Name
* Date and Time of \[last] Status Change
* Status (Pending or Rejected)
* Approval Process Stage (if a multi-step process)

> 👍 Tip
>
> The **Approval Process Queue** allows easier content tracking when an Approval Processes has many steps since it tracks each video’s status through each stage of the process. It should be used particularly if Pending emails are suppressed.
