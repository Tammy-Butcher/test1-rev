[Comments](doc:video-features) provide a means for your users to leave interactive feedback on content that has been added to the system. 

To globally enable comments, select the **Allow comments on all media** checkbox under **Media Settings** > **Features**.

Keep in mind:

- The **Comment** field allows a maximum of 1000 characters.
- Each comment has the user's **Name** and **Date** noted.
- When a user leaves a comment, the video owner receives an email notification of the comment with the commenter’s **Name**, **Date**, and **Time** of the comment, and the comment itself along with a link to it.
- Other users may reply to the original comment to create nested comments.
  - Only one level of nested comments is created.
  - Replies on the second level of comments will reply to the original comment.
  - Email notifications are included for nested comments.
- Users may delete their own comments.
- Account Admins and Media Admins may also delete comments.
- If a comment is deleted, it is replaced with placeholder text: “_This comment has been removed_.”
- Once comments are enabled _globally_, the **Enable Comments** checkbox appears in [video settings](doc:updating-video-settings) which allows comments to be enabled or disabled on individual videos by the owner.
- If this setting is _disabled_ globally, the Enable Comments checkbox no longer appears on individual videos nor will it appear in the [Bulk Edit](doc:bulk-edit-video-settings#enable-comments) interface.
