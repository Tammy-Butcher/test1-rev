When adding video to Rev, you are able to upload it from your hard drive. If you have the **Enable Add URLs** option configured, you are also able to link to URLs to display video. This feature is enabled by default.  

Select the **Allow videos to be added via URLs** checkbox under **Media Settings** > **Features** > **Video Settings** to enable this ability. This adds the [Add URLs](doc:link-to-video-urls) tab to the **Upload Video** icon on the [Header Navigation Options](doc:the-rev-home-page#header-navigation-options).

When Add URLs is _disabled_:

- The **Add URLs** tab is no longer available when **Upload Video** is clicked.
- If a **Live Video** carousel is configured on the **Home Page**, it is removed and the Live Video configuration is longer available as an option for Home Page configuration in the future.
- Any videos uploaded prior to clearing the **Allow videos to be added via URLs** checkbox still appear under **Recent Videos** and are still present in Rev. Users with Admin access may delete these videos if desired.
