While viewing a video on Rev, you are able to specify if recommended videos are displayed below the video that is currently being viewed by selecting the **Enable recommended videos for VOD** checkbox. 

This feature is disabled by default. To enable this feature, select the **Allow recommended videos on all VOD playback pages** checkbox under **Media Settings** > **Features** > **Video Settings**.

When *enabled*:

* There is a grid view of [recommended videos](doc:rev-video-player-features#recommended-videos) that displays under the current video.
* Recommended videos are specific to the user and the current video being viewed.
* If the user has not viewed any videos recently, then the most popular videos of the last seven days based on portal views is displayed instead.
* A **See All** button will take you to the **All Videos** page, sorted by the **Recommended** filter

When *disabled*:

* Only the current video displays with no grid or recommendations present
