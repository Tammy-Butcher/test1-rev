If you have the **Allow Videos to be Hidden from the Rev Interface and Search** option under **Media Settings** > **Features** > **Video Settings** checked, the video is hidden from anyone who does not have edit rights within the Rev UI when it is [unlisted](doc:update-advanced-video-settings#unlist-this-video). This option is disabled by default.

When *enabled* AND a VOD or Live Stream is then *unlisted*, the videos are hidden from anyone who does not have edit rights to the video. This means the video is not searchable/viewable in:

* All Videos
* Categories
* Dashboard carousels including the **Featured Video** carousel
* Channels
* Playlists
* Global Search
* The video may *only* be played when accessed directly via embed code or direct link. 
* Unlisted videos may also be manipulated through Rev APIs.
