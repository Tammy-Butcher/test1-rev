If you have the **Enable 360 Video** option checked, users are able to upload and view [360-degree](doc:upload-video) videos. 

Select **Allow uploading of 360 videos** checkbox under **Media Settings** > **Features** > **Video Settings** to enable. This feature is enabled by default.

When *enabled*:

* This adds the **360 video** checkbox on the **Upload Files** control when adding a new video to the portal.
* Transcoding presets exist for the support of 360 videos and are applied automatically.

When *disabled*:

* The **360 video** checkbox is no longer available when uploading video.
* Any files uploaded *prior* to disabling the **Enable 360 video** checkbox are not deleted or hidden.

> ❗️ Warning!
>
> 360 video file sizes, particularly those that are 4k video, can be very large. This should be taken into consideration for account management usage when viewing and managing 360 videos.
