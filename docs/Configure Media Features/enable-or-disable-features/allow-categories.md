[Categories](doc:video-categories) provide a means to logically group content that is similar. 

To globally enable categories, select the **Allow categories on all media checkbox** under **Media Settings** > **Features** > **Video Settings**.

Keep in mind:

* Categories may have subcategories.
* Category names must be unique within an account.
* Category names have a maximum of 100 characters and a minimum of 1 character.
* When deleting a category, content assigned to that category is not deleted; only the association to the category itself is removed.

When categories are *disabled*:

* A category is not selectable when media is uploaded.
* Category details are not displayed on any video page.
* Category **filter** options are removed from video search pages.
* **Category Management** is no longer available for Account Admins.
* The option to [Bulk Edit](doc:bulk-edit-video-settings#categories) categories is no longer available.
* If categories are disabled *after* a category has already been used, the category is not deleted from the database. However, its display is discontinued as noted. (video pages, upload pages, search fields, etc.)
