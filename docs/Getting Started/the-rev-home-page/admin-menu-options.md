Click the **Gear** icon in the upper right corner of the [Header navigation options](doc:the-rev-home-page#header-navigation-options) to access Rev's **Admin** menu features and functions.

<Image align="center" alt={34} border={false} caption="Admin menu Gear icon" title="admin gear.png" src="https://files.readme.io/4590e02-admin_gear.png" />

> 🚧 Important!
>
> Only Rev accounts with **Admin** access have the **Gear** icon present.  Also, only _specific_ Admin roles have access to the _entirety_ of the Admin menu functions available.
>
> If you do not have Admin menu access or access to certain features, this means you do not have the permissions assigned to your account that you likely need.

## Admin Menu Header Navigation Options

The options available on the Admin **Header** navigation vary depending upon your [permissions](doc:roles-and-permissions) and account access. For example, **Media Admin** options include only the [Media Settings](doc:define-media-settings) menu.

<Image align="center" alt={805} border={false} caption="Admin menu Header navigation menu" title="admin header nav options.png" src="https://files.readme.io/6a796e9-admin_header_nav_options.png" />

| Menu Option                                 | Description                                                                                                                                                                                                       |
| :------------------------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Parent / Child Account Dropdown (Not shown) | Provides the ability to navigate between any Parent and [Child Account](doc:view-and-edit-account-details#portal-child-accounts). Display is defaulted to Parent account.                                         |
| Reports                                     | Access to various [system analytics and reports](doc:view-system-analytics) about your Rev portal.                                                                                                                |
| Users                                       | Details on creating, activating, and managing Rev [user accounts](doc:user-accounts#add-or-edit-a-user). Also nests the Groups, Channels, and Roles menus.                                                        |
| Devices                                     | How to manage [Devices](doc:getting-started-with-rev-devices), [Presentation Profiles](doc:add-a-presentation-profile), and [Zones](doc:manage-and-add-zones).                                                    |
| Media Settings                              | Covers how to configure [Media Settings](doc:media-settings-guides) for content in Rev including Categories, Player Settings, Recording Settings, Transcoding Presets, Features, and creating Approval Processes. |
| System Settings                             | Explains detailed [System Setting](doc:set-system-features) and security information such as User Password Parameters, API Keys, and your system Environment.                                                     |
| Accounts                                    | Management of your Rev portal including the [Contact & Billing](doc:view-and-edit-account-details) and [Child Accounts](doc:view-and-edit-account-details#portal-child-accounts) modules.                         |
