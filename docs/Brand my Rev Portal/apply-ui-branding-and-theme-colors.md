Access Rev's Branding options through the **Admin > System Settings > Branding** menu option.

Most of Rev's UI and branding automatically applies the theme and colors selected in the **Branding** menu under the **General** tab.  Keep this in mind if you modify these default color options.  For example, the branding and colors for [login and account options](doc:your-rev-account) as well as some parts of the portal [Header](doc:customize-the-portal-header) are based on the default colors below.

<Image alt="Many UI branding and theme colors are automatically applied based on options you select in the Branding menu" align="center" src="https://files.readme.io/1841ba82537665fb122926a3faf78efafbec022ba015ec375ea1d6ecd27ae45c-defaultColors.png">
  Many UI branding and theme colors are automatically applied based on options you select in the Branding menu
</Image>

Modifying branding colors will also modify several aspects of your portal's UI and theme components automatically including the following:

* Login and embedded login screens
* Login / Logout message(s)
* New user confirmation / User agreement form(s)
* Password and security question reset screens
* Password reset limit
* oAuth login/ Rev IDP oAuth form(s)
* System Message

<Image title="newUserConfirmation.png" alt="Login Screen with default Branding colors" align="center" src="https://files.readme.io/f0c278c0daba4faae27c4dc1f1b63d1b02c34d7b839152e18a36004874e3c784-loginDefaultColors.png">
  Login Screen with default Branding colors
</Image>

In general, modifying the default colors affects the following areas of your portal:

* **Primary Color**: Background color of all *inner* components and forms for the portal.  Includes items such as the VOD sidebar(s), playlist embedding layouts (grid, slider, etc.), search filters, and bulk action sidebars.  The exception is the Header and Featured Video forms.
* **Primary Font Color**: The font color of all *inner* components and forms for the portal.  Includes items such as the VOD sidebar(s), playlist embedding layouts (grid, slider, etc.), search filters, and bulk action sidebars.
* **Accent Color**: Taken mainly from the company’s main branding color (for example, if your organization’s main branding is blue, the accent color will be blue).
* **Accent Font Color**: Remaining font colors not on inner components and forms.
* Click the **Reset Default** button to reset any customization to the default color
