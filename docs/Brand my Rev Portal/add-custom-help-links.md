You are able to create additional help links for Rev and modify the default help link if you want to include your own branded help topics for your organization.  You can always reset to the default Rev online help should you need to retrieve Rev's help files.

To modify and create additional help options, Account Admins access the **Branding** menu under **System Settings**.  The **Header** tab contains the **Help Links** section.

<Image title="customHelpLinks.png" alt={998} src="https://files.readme.io/41724e7-customHelpLinks.png">
  The Help Links section under the Branding Menu customizes the portal help section if needed
</Image>

1. The **Customize Default Help Link** field modifies the default Rev help URL. Note that if you change this link, the portal is no longer linked to \[this] Rev’s default (and official version) help files. To view the default Rev help and add your own help settings, add an **Additional help link** instead.

2. Add **Additional help links** by clicking the drop-down and specifying an **Email Address** or **URL**. Enter a description and a URL or email address.

3. The **Reset Default** button returns Rev's default help link.  The **Add Help Link** adds another link field.  Click **Save** to add your custom help links.  They now appear when the Help icon in Rev is clicked.

<Image title="customHelpLinksSaved.png" alt={1092} src="https://files.readme.io/24accc5-customHelpLinksSaved.png">
  You are able to add new URLs and email addresses and event customize the default help
</Image>
