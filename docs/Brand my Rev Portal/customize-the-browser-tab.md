## Add a Custom System Title

You can use the **System Title** field under the **General Tab** to customize the browser tab. It changes the default **Vbrick** system title and is used for [accessibility purposes](doc:accessibility-features).  The table below demonstrates the areas where System Title is used if you elect to change it from the default Vbrick.

| Rev Page             | New Tab Title                                 |
| :------------------- | :-------------------------------------------- |
| Homepage             | Homepage - **Vbrick**                         |
| Real Time Dashboard  | Real Time Dashboard - **Vbrick**              |
| Browse Categories    | Categories - **Vbrick**                       |
| Category             | {{CategoryName}} - Category - **Vbrick**      |
| Subcategory          | {{SubCategoryName}} - Category - **Vbrick**   |
| My Subscriptions     | My Subscriptions - **Vbrick**                 |
| Manage Subscriptions | Manage Subscriptions - **Vbrick**             |
| Expirations          | Expirations - **Vbrick**                      |
| Notifications        | Notifications - **Vbrick**                    |
| My Profile           | My Profile - **Vbrick**                       |
| Video Player Page    | {{Video Title}} -  Video Player - **Vbrick**  |
| Edit Video           | {{Video Title}} - Edit Video - **Vbrick**     |
| Live Webcast         | Webcast - **Vbrick**                          |
| Event Calendar       | Event calendar - **Vbrick**                   |
| Event Settings       | Webcast Event Settings - **Vbrick**           |
| All Videos           | Videos - **Vbrick**                           |
| Search results       | Videos - **Vbrick**                           |
| My Videos            | My Videos - **Vbrick**                        |
| My Playlists         | {{playlist name}} - My Playlists - **Vbrick** |
| Channels             | Channels - **Vbrick**                         |
| Channel              | {{ChannelName}} - Channels - **Vbrick**       |
| Edit Channel         | Edit Channel - **Vbrick**                     |
| Unauthorized         | Unauthorized - **Vbrick**                     |
| Log-In               | Sign In - **Vbrick**                          |
| Admin                | Admin- **Vbrick**                             |
| Bulk Edit            | Bulk Edit - **Vbrick**                        |
| Video Details        | {{Video Title}} - Video Details - **Vbrick**  |

## Add a Custom Favicon Image

You can upload a custom favicon image for your browser file by selecting the **Choose File** button and uploading an image from your harddrive. The image must be a 1:1 (square) image and one of our [Supported File Types](doc:supported-file-types) or an .ico format.
