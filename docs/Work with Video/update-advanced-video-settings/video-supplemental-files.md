To update **Video Settings** in Rev:

1. Navigate to a video and hover over the **Video Settings** button in the top right corner.

2. Click **Details ** from the options that appear.  Several tabs appear that allow you to create and modify the video's metadata. Select a tab depending on which setting you want to update. 

3. This feature is an **Advanced Setting**.

**Supplemental files** are attached to videos so that viewers may download and view them at their own speed. This includes files such as Excel spreadsheets, PDF documents, and PowerPoint presentations among other [supported file types](doc:supported-file-types). This ability must be [enabled](doc:allow-supplemental-content) by an Account Admin first before this feature is available.

- Click the **Add Files** button in the **Supplemental Files** section to attach a file.
- You may specify a name for the file or the file name itself is used otherwise

> 📘 Note
> 
> To use a different name than the filename, upload the file first, click save, and then edit and rename it. The **Edit **option (seen in the image above) is _not_ available until you save the file.

- Use the **Delete **option to remove a file from the video
- Supplemental files appear for download on the [Video Basic Information](doc:rev-video-player-features#video-basic-information) flyout panel

> 👍 Tip
> 
> If you are a Rev IQ user and use the Video Assistant, you can choose to enabled [Enhanced Multimedia Analysis](doc:enhanced-multimedia-analysis) for the [Vbrick Assistant](doc:vbrick-assistant). If you do so, some supplemental files are also analyzed for answers in addition to the video's transcript.
