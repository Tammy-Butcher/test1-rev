Use the [Unlisted](doc:unlist-a-video) control in the [Bulk Edit](doc:bulk-edit-video-settings) interface to edit the unlisted video setting on several videos at once. If the **Unlisted** checkbox is selected, the video is not visible or viewable anywhere in the Rev interface.  This control enables or disables this ability.
