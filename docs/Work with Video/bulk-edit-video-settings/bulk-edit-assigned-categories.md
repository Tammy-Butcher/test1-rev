Use the [Categories](doc:video-categories-and-tags) control in the [Bulk Edit](doc:bulk-edit-video-settings) interface to add, remove, or replace one or more categories to several videos at once. If you are adding a category to video(s), it must already exist in the system. You may not create and add categories at the same time.

Select which action you want to perform and then choose the categories to perform the action on before clicking **Save**.  For example, the Government and Training categories will be added to the selected videos.

- **Add ** adds a category to those already in place on the video.  No category already in place is modified.
- **Replace** completely removes all categories currently on the video(s) and replaces them.
- **Remove** deletes  all categories entirely and nothing new is added.

> ❗️ Warning!
> 
> You are not able to bulk edit a **Secure Category** if you do not have permissions to do so as either a **Category Contributor** or **Category Manager**.
> 
> **View**: [Media Settings Roles and Permissions](doc:roles-and-permissions#section-media-settings)
