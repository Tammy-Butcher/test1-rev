Use the [Comments](doc:video-features#enable-comments-ratings-and-downloading) control in the [Bulk Edit](doc:bulk-edit-video-settings) interface to edit the comments video setting on several videos at once. If the **Enable Comments** checkbox is selected, the video may be commented on by the viewer.  This control enables or disables this ability.
