Use the [Bulk Edit](doc:bulk-edit-video-settings) function to set the [Status](doc:video-status) of several videos at once to either **Active** or **Inactive**. You may set an **Expiration** date and delete the videos once they expire or set a **Publish** date in the future depending upon which status is set.

In the **Status** dropdown, select which status state you want to set. In the example below, all selected videos will have an **Active** status applied. 

<Image title="statusDropdown.png" alt="Selected videos will have the Active status applied" align="center" src="https://files.readme.io/3eb4342-activeStatus.png">
  Selected videos will have the Active status applied
</Image>

> 📘 Note
>
> By default, if you choose an **Active** status and do not choose a **Publish** date, the current date is applied.

Use the [Expiration](doc:video-publish-and-expiration-dates#set-an-expiration-date-or-rule) control to replace or remove an expiration date or rule on several videos at once.

1. Select **Active** in the **Status** dropdown.

2. Select **Replace** in the **Expiration** dropdown if you want to replace a previously set expiration date or rule. Select **Remove** if you want to remove previously set expiration dates or rules entirely.

<Image title="replaceExpireDate.png" alt="Select an Active Status and then Replace or Remove in the Expiration dropdown to update the date" align="center" src="https://files.readme.io/9279243-expireDateSet.png">
  Select an Active Status and then Replace or Remove in the Expiration dropdown to update the date
</Image>

3. Notice in the image above that if you select to replace an expiration date, you can also choose what action to take once the videos expire; Delete them (or set them to **Inactive** status by default by leaving the setting unchecked).
