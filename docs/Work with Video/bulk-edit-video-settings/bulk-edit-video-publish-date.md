Use the [Publish Date](doc:video-publish-and-expiration-dates#set-a-publish-date) and Status control(s) in [Bulk Editing](doc:bulk-edit-video-settings) to replace or remove the publish date(s) of several videos at once.

1. Set the video status to **Inactive **if it **Active**.  To update publish date(s), the video must be **Inactive**.  The only exception to this is if you are updating the publish date to the current (today's) date.

2. Select **Replace **in the **Publish** dropdown if you want to replace a previously set publish date. Select **Remove **if you want to remove previously set publish dates entirely.

3. To publish a video in the future, as noted, you must set its status to **Inactive **(if it is **Active**).
