Use the [Show Chapter Images By Default](doc:video-features#show-chapter-images-by-default) control in the [Bulk Edit](doc:bulk-edit-video-settings) interface to enable or disable the default display of chapter images in a video from several videos at once.

      ],
      "align": "center",
      "caption": "Select Enabled to display Chapter Images by default for those videos that have chapters"
    }
  ]
}
[/block]


Keep in mind that the video must have chapters and at least one image for this feature to function. Viewers can always disable the images (if this is enabled) by toggling the [Show Chapter Images](doc:rev-video-player-features#playback-bar-functions) icon in the video player.
