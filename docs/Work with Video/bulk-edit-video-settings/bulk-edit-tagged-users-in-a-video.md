Use the [In This Video](doc:tag-users-in-a-video) control in the [Bulk Edit](doc:bulk-edit-video-settings) interface to add, replace, or remove tagged users in a video from several videos at once.

<Image title="appendInThisVideo.png" alt="Select the action to take in the In This Video control and the users in the Find control" align="center" src="https://files.readme.io/294e337-inThisVideoBulkEdit.png">
  Select the action to take in the In This Video control and the users in the Find control
</Image>

1. Select which setting you want to apply on the videos you have selected in the **In This Video** dropdown.

2. Enter the user accounts to apply your selection to in the **Find** control:
   * **Add** adds (tags) the identified users in addition to those users already tagged.
   * **Replace** wipes any users already tagged (removes the tags) on the videos and replaces (tags) them with the user accounts that are added.
   * **Remove** removes all currently tagged users and the videos will retain no tagging.
