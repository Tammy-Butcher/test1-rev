To update **Video Settings** in Rev:

1. Navigate to a video and hover over the **Video Settings** button in the top right corner.

2. Click **Details ** from the options that appear.  Several tabs appear that allow you to create and modify the video's metadata. Select a tab depending on which setting you want to update. 

3. This feature is a **Basic Setting**.

Select a category or a subcategory from the **Categories ** control. Note that a subcategory has its parent category label below it.  The image below demonstrates that the Subtitles and Closed Captioning categories are both subcategories of the parent category AV Videos for example.

> 👍 Tip
> 
> You are only able to view (and add) categories you have permissions to view. Use the **Browse Categories** option from the [User > Media](doc:user-menu-options) menu to view those categories.
