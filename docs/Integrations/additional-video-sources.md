You can globally enable or disable additional video sources in Rev in this section.

## Allow Existing Video

When you select the **Existing Video** checkbox, you allow Event Hosts to use a previously existing video as a video source during event set up. This setting must be enabled for this feature to be used.

View: [Existing Video Event Set Up](doc:existing-video-sourced-events) for details.

## Allow Webcam and Screenshare Events

When you select the Webcam & Screenshare, Screen Recording, and Producer checkbox, you allow Event Hosts to use Webcam & Screenshare as a video source during event set up. This setting must be enabled for this feature to be used.

View: [Webcam and Screenshare Event Set Up](doc:webcam-and-screenshare-events) for details.
