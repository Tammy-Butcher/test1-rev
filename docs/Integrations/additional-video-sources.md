You can globally enable or disable additional video sources in the **Admin > Media Settings > Integration > Additional Video Sources** section.  Each is described below.

## Allow Existing Video

When you select the **Existing Video** checkbox, you allow Event Hosts to use a previously existing video as a video source during event set up. This setting must be enabled for this feature to be used.

View: [Existing Video Event Set Up](doc:existing-video-sourced-events) for details.

## Allow Webcam & Screenshare, Screen Recording, and Producer

When you select the Webcam & Screenshare, Screen Recording, and Producer checkbox, you enable the features below.

### Allow Webcam and Screenshare Events

When this checkbox is enabled, Event Hosts are able to select **Webcam & Screenshare** as a video source during event set up. This setting must be enabled for this feature to be used otherwise it will not be visible in the drop-down.

View: [Webcam and Screenshare Event Set Up](doc:webcam-and-screenshare-events) for details.

### Allow Screen Recording

When this checkbox is enabled, the **Rev Screen Recorder** is available to record and share videos directly from your web browser. This setting must be enabled for this feature to be used otherwise it will not be visible to launch from your Header navigation or in the Upload tray.

View: [The Rev Screen Recorder](doc:screen-share-and-record) for details.

### Allow Producer

When this checkbox is enabled, Event Hosts are able to select **Producer** as a video source during event set up. This setting must be enabled for this feature to be used otherwise it will not be visible in the drop-down.

View: [Producer Event Set Up](doc:producer-event-set-up) for details.
