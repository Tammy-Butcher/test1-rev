Roles are groups of permissions to system features that you assign to **Groups** and **Users**. For example, a **Media Viewer** role is able to view content but not edit or approve it whereas an **Account Admin** role is able to manipulate virtually every setting in the system. The roles and permission features of Rev ensures that each user has access to *only* the features that are needed.

There are also [Channel](doc:channel-roles-and-permissions) roles and permissions that are entirely separate from the standard Rev roles and permissions so that Channels are separate entities that may be managed on their own.

Finally, Rev also has a set of **Granular** roles and permissions that are very specific to what you need an account to be able to do while restricting them to other functions. For example, you might need an **Event Analytics** account to grant a user access to *only* event analytics (which admin accounts can also view) while *not* giving them admin permissions.

## Viewing Roles

To access the predefined roles in Rev:

1. Navigate to **Users** > **Roles** menu in the [Admin Menu Options](doc:admin-menu-options).
