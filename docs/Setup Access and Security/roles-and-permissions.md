Roles are groups of permissions to system features that you assign to **Groups **and **Users**. For example, a **Media Viewer** role is able to view content but not edit or approve it whereas an **Account Admin** role is able to manipulate virtually every setting in the system. The roles and permission features of Rev ensures that each user has access to \_only \_the features that are needed.

There are also [Channel](doc:roles-and-permissions#channel-roles-and-permissions) roles and permissions that are entirely separate from the standard Rev roles and permissions so that Channels are separate entities that may be managed on their own.

Finally, Rev also has a set of [Granular](doc:roles-and-permissions#granular-roles-and-permissions) roles and permissions that are very specific to what you need an account to be able to do while restricting them to other functions. For example, you might need an **Event Analytics** account to grant a user access to _only_ event analytics (which admin accounts can also view) while _not_ giving them admin permissions.

## Viewing Roles

To access the predefined roles in Rev:

1. Navigate to **Users **> **Roles **menu in the [Admin Menu Options](doc:admin-menu-options). 

2. **Permissions **and a brief **Description **is listed for each role.

## Channel Roles and Permissions

Rev also has Channel roles and permissions that are separate from Rev roles though they are similar in function. Channel roles and permissions relate \_only \_to the management of a Rev channel. Further, Rev roles do \_not \_have permissions within the scope or context of a Channel, and this includes a Rev Account Admin. Instead, Admins need to access the Channel through the Users menu if needed.

> 🚧 Important!
> 
> You should always make sure that your Channels have _at least one_ **Channel Admin** assigned when you create a Channel so that you have someone in charge of managing the Channel settings and members. 

Because Channel roles are separate from Rev roles, this means that you may designate a non-admin account in Rev as a Channel Admin for a Channel if you so choose.
