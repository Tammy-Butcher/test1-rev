You must have the **Account Admin** role to manage user account passwords in Rev. This includes resetting a password for a user, unlocking an account, resetting a security question, and suspending users.  Account Admins define password settings and rules in [System Settings](doc:set-portal-password-rules).

You can check the status of a user's account (and password) in the [Access Management](doc:add-a-local-user-account#user-access-management) section of their user account page.

To manage a user's password in Rev:

1. Navigate to **Admin** > **Users **> **Users** menu in the [Admin Menu Options](doc:admin-menu-options).
