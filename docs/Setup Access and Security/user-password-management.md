You must have the **Account Admin** role to manage user account passwords in Rev. This includes resetting a password for a user, unlocking an account, resetting a security question, and suspending users.  Account Admins define password settings and rules in [System Settings](doc:set-portal-password-rules).

You can check the status of a user's account (and password) in the [Access Management](doc:add-a-local-user-account#user-access-management) section of their user account page.

To manage a user's password in Rev:

1. Navigate to **Admin** > **Users** > **Users** menu in the [Admin Menu Options](doc:admin-menu-options). 

<Image alt="The Users Menu is accessible to Account Admins under the Users Header Navigation Menu" align="center" src="https://files.readme.io/568e6a112fd2adec23eb850778def0051ee2f9c8d3dfbd6a82c333f7e00ef0ac-usersMenu.png">
  The Users Menu is accessible to Account Admins under the Users Header Navigation Menu
</Image>

2. The **Users** module is displayed.  The status of each user account is displayed in the **Status** column and includes password states where applicable.

<Image align="center" src="https://files.readme.io/f1d618d30288d41b43fac484ac15d76d8943cdac84d800b631a4b5723688bdc6-userAccountStatusColumn.png" />

3. To manage a user's password, click on the *specific* user and scroll to the **Access Management** section. The **User State** displays the current **status** of the specific user password that you have selected.

<Image alt="The User State field displays that this user's password expired 75 days ago." align="center" src="https://files.readme.io/2b244dee04fb6f709562c9e38ad83d237bfa36c68fe5e5d7c9589dd1672e5065-accessManagementExpiredPassword.png">
  The User State field displays that this user's password expired 75 days ago.
</Image>
