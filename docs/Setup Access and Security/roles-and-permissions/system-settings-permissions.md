**System Settings** permissions in Rev are strictly limited to the Account Admin role. No other role has these permissions at present.  These permissions include:

- Edit security settings
- Add/edit/delete API keys
- Edit environment settings (Root account access only)
- Edit UI branding
- Add/edit/delete custom fields
- Add/edit/delete webcast registration fields
