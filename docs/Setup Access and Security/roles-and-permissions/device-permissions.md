Creating and managing [devices](doc:getting-started-with-rev-devices) is strictly limited to the Account Admin role in Rev. No other role has these permissions at present.  Included permissions are:

* Add/edit/delete devices
* Add/edit/delete zones ¹
* Add/edit/delete presentation profiles
* Manage set top boxes
* Manage display boxes

<sup>1: Note that not all devices may be displayed here as more are added to Rev. Permissions remain the same however in that you must have the Account Admin role to add and manage them.</sup>
