Use the **Download** button on the **Users** module to export a CSV file of all Users in the system. For those portals that have large amounts of Users, the download process prepares in the background. A notification and email are sent to the Admin Account that prompts the download when it is ready.

<Image title="downloadPrep.png" alt={534} align="center" src="https://files.readme.io/0b26a3d-downloadPrep.png">
  If necessary, the download is prepared in the background and you are notified when it is ready
</Image>

The following fields are contained in the download:

* Username
* First Name
* Last Name
* Email Address
* Title
* Phone Number
* Status
  * Active
  * Unlicensed
  * Awaiting Password Reset
  * Awaiting Security Question Reset
* Licensed
  * True or False
* Preferred Language
* Roles
* Group Assignments
* LDAP Group Assignment
* Channel Names
* Source
  * System
  * LDAP
