Use the **Role Assignment** and **Group Assignment** controls to assign (or remove) roles and groups to a user as needed.

There are several [pre-defined roles](doc:roles-and-permissions) that may be added to a user account.  The **Media Viewer** role is assigned by default. At least one role must be assigned or you will not be able to save the user account.

Assign roles (and their associated permissions) to a user by moving them from the **Available Roles** column to the **Assigned Roles** column. Moving roles between the two columns adds and removes that role to and from the user. The **Media Viewer** role is the only role assigned by default when the user is first created.

<Image title="assignRoleToUser.png" alt={1075} align="center" src="https://files.readme.io/834f7ab24d72d3eda142e0fe33e0efa91ed231019439c987941587a9e61b42ac-roleAssignmentControl.png">
  Assign and remove roles to a user by adding and removing them between the Available and Assigned Role columns
</Image>

To add the user to a **Group**, type the group name in the **Find Items** box. Click the name and then **Done** to add the group to the **Group Assignment**.  This adds the user to the **Group** upon saving.

To remove a user from a group, click the **X** next to the group name.

<Image title="assignGroupToUser.png" alt={947} align="center" src="https://files.readme.io/b9411b8-assignGroupToUser.png">
  Any groups typed in the Find Items box appear automatically so that you may add the User to the group
</Image>

> 📘 Note
>
> It is not a requirement that a group is assigned when creating or editing a User. You may also add a user account to several groups at once using the upload functionality.
