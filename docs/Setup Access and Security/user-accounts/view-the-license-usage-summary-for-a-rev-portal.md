The **Users Module** displays at a glance how many total Users are in your portal and how many licenses you have consumed versus how many remain unused.

Keep in mind:

- Users are _not_ counted as [Licensed](doc:rev-license-types-and-add-ons) users until they log in and verify their account.
- **Unlicensed **and **Suspended **status states do _not_ count toward the number of Licensed users displayed.
- **Active**, **Locked Out**, **Awaiting Password Reset**, and **Awaiting Security Question Reset** _do_ count toward the number of **Licensed **users for a Rev portal.
- If a user attempts to log in to a Rev portal that does _not_ have any licenses available, the user will not be able to log in and a message is displayed to contact the Rev Account Administrator.
