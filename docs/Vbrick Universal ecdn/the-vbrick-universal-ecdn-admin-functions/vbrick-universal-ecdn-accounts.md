The **Accounts** option under the **Admin** menu consists of tabs and data created to assist Account Admins in maintaining their Vbrick account information.

> 👍 Tip
> 
> The **Accounts** page is consistent across all Vbrick cloud products.

Clicking on **Edit** or **+ Add Account** provides access to account details (to be edited or entered respectively) that contain common account setting information and that are a subset of the information already found on the [Vbrick Rev Accounts](doc:view-and-edit-account-details#account-name-and-account-host-name-settings) page.  Please view that help page for the definitions of the common fields and note that only fields associated with the **Vbrick Universal eCDN** are displayed here.

For accounts provisioned by Vbrick, they will already be set to **License Type** as **Concurrent Users**, the **Modules** section will be set to **Vbrick Universal eCDN**, and the **Licensed Concurrent Users Count** will be defined by the sales contract.  These are all pre-configured for your top-level account.

Additional details on other sections and settings mirror the [Vbrick Rev Account menu](doc:view-and-edit-account-details) including the ability to create [Child Accounts](doc:view-and-edit-account-details#portal-child-accounts).
