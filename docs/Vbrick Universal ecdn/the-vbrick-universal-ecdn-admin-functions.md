The **Vbrick Universal eCDN Admin** functions are accessible through a Gear cog similar to Vbrick Rev in the upper right corner of the Header navigation.  Many of the same menu options are available here that are seen in the [Vbrick Rev Admin menu](doc:admin-menu-options) when you click this icon.

<Image alt="The Vbrick Ramp eCDN Admin Menu is similar to the Vbrick Rev Admin Menu" align="center" src="https://files.readme.io/f99c465-rampAdminMenu.png">
  The Vbrick Universal eCDN Admin Menu is similar to the Vbrick Rev Admin Menu
</Image>

Though the two Admin menus are similar, the Universal eCDN does not contain the full functionality of Vbrick Rev.  Each topic in this section explains how they differ.
