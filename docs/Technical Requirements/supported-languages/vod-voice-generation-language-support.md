The [Rev IQ Transcription and Translation](doc:rev-iq-transcription-and-translation) services support the following languages to auto generate up to ten audio tracks if they have a transcription file in place.  Please note that you must have Rev IQ enabled to use these features.

| :--------------------- | :------------ | :-------- |
| Chinese (Mandarin)     | cmn-CN        | Zhiyu     |
| Danish                 | da-DK         | Sofie     |
| Dutch                  | nl-NL         | Laura     |
| English (Australia)    | en-AU         | Nicole    |
| English (British)      | en-GB         | Amy       |
| English (US)           | en-US         | Joanna    |
| French                 | fr-FR         | Lea       |
| French (Canadian)      | fr-CA         | Gabrielle |

| Korean                 | ko-KR         | SeoYeon   |
| Norwegian              | nb-NO         | Ida       |
