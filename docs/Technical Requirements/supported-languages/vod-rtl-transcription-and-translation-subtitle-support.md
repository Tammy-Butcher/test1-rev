The [Rev IQ Transcription and Translation](doc:rev-iq-transcription-and-translation) services support the following **Right-to-Left (RTL) languages** to use for your VOD uploads.  Please note that you must have **Rev IQ** enabled to use these features.

## VOD RTL Transcription Languages

| RTL Transcription (Source) Languages | Code   |
| :----------------------------------- | :----- |
| Arabic (Gulf)                        | ar-ae  |
| Arabic (Modern Standard)             | ar-sa  |
| Central Kurdish (Iran)               | ckb-IR |
| Central Kurdish (Iraq)               | ckb-IQ |
| Farsi (Persian)                      | fa     |
| Hebrew                               | he     |
| Pashto                               | ps     |
| Uyghur                               | ug     |

## VOD RTL Translation Languages

| RTL Translation Languages | Code |
| :------------------------ | :--- |
| Arabic                    | ar   |
| Dari                      | prs  |
| Farsi (Persian)           | fa   |
| Hebrew                    | he   |
| Pashto                    | ps   |
| Urdu                      | ur   |
