Event Hosts are able to theme individual webcasts and apply custom branding if needed using the **Event Branding** section. Custom branding options can also be saved to [webcast templates](doc:create-a-webcast-template) to be used as often as needed.

By default, your webcast will use the Account-level branding configured in the Admin Console. However, you can also provide a completely customized look and feel for any event.

Enable the **Custom Branding** tab if it is disabled and modify the options as needed for the individual event  following the [branding guidelines](doc:rev-branding-and-style-guides) available in the Rev portal as a whole.

The branding settings appear in the following locations once saved:
* Webcast view
* Webcast slides (if applicable)
* All sidebars (Admin/Attendee views)
* Recordings (if applicable)

Click the **Preview Event** button to view a full screen preview of the attendee view with your current branding settings applied (your presentation upload does not display in this view).
