In the case of technical difficulties, Event Admins and Hosts have the ability to review the **Video Source** for the event in the **Event Details** (this requires clicking the **Edit Settings** button) [during an ongoing webcast](doc:edit-settings-during-an-ongoing-webcast).  The following video sources are currently supported for this feature:

* Video Address
* Microsoft Teams
* RTMP/RTMPS

Further, depending on the type of **Video Source** , you also have the ability to restart (or reconnect) to the video source such as displayed in the image below where the source is is a  **Microsoft Teams** URL.

<Image alt="Expand the Video Source section and click the Restart Video Source button to restart the webcast" align="center" src="https://files.readme.io/ee6fe93-restartVideoSource.png">
  Expand the Video Source section and click the Restart Video Source button to restart the webcast
</Image>

When the **Video Source** section of the **Event Details** panel is accessed, Video Source information is displayed that was configured during event setup. For example, in the case of an RTMP/RTMPS stream, the Push URL and Stream Key are displayed.

<Image align="center" src="https://files.readme.io/3ec085af09848aa30051b06edafadb87d8367ee54386e954ff8d382d0fa230e9-rtmpRestartVidSource.png" />

Clicking the **Restart Video Source** button will restart the source without ending the event. You are also able to send a message to Attendees of the event that it is being restarted so there is no confusion as to what is occurring on their end.

<Image align="center" src="https://files.readme.io/1cbfc89-restartSourceMessage.png" />

> 👍 Tip
>
> Attendees of the event only see the **Message to Audience** that you enter.

Once the event has restarted, you must click the **Broadcast** button to begin broadcasting it again.

<Image align="center" src="https://files.readme.io/e24ca96-broadcastEventButton.png" />

> 📘 Note
>
> Additional video sources will be added in the future as this feature continues to develop.
