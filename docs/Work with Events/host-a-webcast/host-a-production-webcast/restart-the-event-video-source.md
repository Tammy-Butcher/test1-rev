In the case of technical difficulties, Event Admins and Hosts have the ability to review the **Video Source** for the event in the **Event Details** (this requires clicking the **Edit Settings** button).  Further, if the **Video Source** is either a **Video Address** or **Microsoft Teams** URL, hosts will have the ability to restart (or reconnect to) the video source.

When the **Video Source** section of the **Event Details** panel is accessed, Video Source information is displayed that was configured during event setup.  

Clicking the **Restart Video Source** button will restart the source without ending the event. You are also able to send a message to Attendees of the event that it is being restarted so there is no confusion as to what is occurring on their end.

> 👍 Tip
> 
> Attendees of the event only see the **Message to Audience** that you enter.

Once the event has restarted, you must click the **Broadcast** button to begin broadcasting it again.

> 
> This function works with [Video Address](doc:video-conference-vc-integrations#configuration) and [Microsoft Teams](doc:microsoft-teams) URL sourced events.  Additional video sources will be added in the future.
