An alternative to _scheduling_ a Live webcast is to use the **Go Live** button to begin broadcasting to an audience _immediately_.

> 👍 Tip
> 
> It is very important that you test this feature within your environment.  There are differences in browsers and internet connections that can impact the quality.  
> 
> As always, please verify the quality and flow before using within event.  Please review the [Rev Screen Share and Webcam Best Practices](doc:rev-screen-share-and-webcam-best-practices).

Once you have configured your **Go Live** settings, click the **Next **button to [Start the Event](doc:host-a-self-produced-webcast#start-the-event).  

Starting a **Go Live** event performs exactly as described above when [hosting a scheduled event](doc:host-a-production-webcast).
