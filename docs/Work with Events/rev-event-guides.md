Rev's virtual event system allows you to host large scale digital webcasts where you control the attendance size and implement dynamic webcast features such as Q&A, polls, and chat; all while allowing your audience to watch a live speaker simultaneously with perfect video quality.

<h3>Usage Guides</h3>
Webcast usage guides provide attendees tips on accessing the various Rev webcasts that are available in the portal.  This includes how to use the features that may be part of a webcast such as chat, polls, and asking questions.
