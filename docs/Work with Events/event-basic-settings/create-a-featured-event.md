You may have an important webcast that you want to draw special attention to or that you want to make sure is noticed. **Featured Events** are displayed in the Home page carousel to those with permissions to see them until the event has ended.

To make an event a Featured Event, an Event Admin or Account Admin must enable the setting in the **Basic Settings** section during event set up.

<Image align="center" src="https://files.readme.io/31e92cf70eceb01bd360ff0eb5f4f9e0d3a46a57004aa8af50accbf7eb0ed312-enableFeaturedEvent.png" />

> 📘 Note
>
> Keep in mind that only events scheduled within 30 days are displayed even if they are **Featured Events**. This means that events scheduled 60 days out, for example, are *not* displayed in the **Home page** carousel until they occur within the 30-day calendar window.
>
> This also means that if you want the event to be featured 3 days (only) before it occurs, you should wait that 3 days *before* the event is scheduled to begin *before* enabling the **Featured Event** toggle.

Upload an **Event Thumbnail** image to use as the Featured Event's background on the Home page carousel.  Note that this is a different setting than the Background Image.  For best results, use a supported image that has a 16:9 aspect ratio and that is at least 1080px wide.

<Image align="center" src="https://files.readme.io/a8fad3fb063a1976ecd546f2848d00dba8cbcffb0dc8c8d456360d252d9fd6ed-eventThumbnailImage.png" />

Once you have tagged the event as a Featured Event, your Account Admin can choose to display them under the **Branding** menu in Rev when customizing [Featured Video](doc:customize-the-featured-video-playlist) content options.

Depending on how your Account Admin has branded your **Home** page, your Featured Events will display in the Home page carousel (if enabled) similar to the image below. In this particular example, the admin configured the Home page carousel to display Featured Events along with Featured Video content.

<Image alt="A Rev Home Page with the Tiles Featured Video template displaying Featured Events + Playlist content" align="center" src="https://files.readme.io/3ad47ce0ecc238a3cec96660efa3dc33199fd333a4c2e916bae55bad52760c1e-featuredEventHomepageImage.png">
  A Rev Home Page with the Tiles Featured Video template displaying Featured Events + Playlist content
</Image>

As mentioned, once the event concludes, it no longer displays on the Home page carousel as a Featured Event.

Please note that if you do *not* upload an **Event Thumbnail** for your Featured Event, Rev displays a placeholder image instead for the event as seen in the image(s) below.
