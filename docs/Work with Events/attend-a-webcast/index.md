There are several methods of joining a webcast depending on the type of event it is and how it has been set up.

> 👍 Tip
>
> If you are having issues accessing your webcast, double check the Start Date and Time first.  Check your event invitation (if you were sent one) to see if the Event Host provided a point of contact for assistance.

## Join From the Upcoming Events Carousel

If an event has been designated as a Public event or available to Rev Users, you are able to see it on the **Upcoming Events** carousel on the [The Rev Home Page](doc:the-rev-home-page) .

> 📘 Note
>
> **Upcoming Events** must be one of the carousel options configured on Rev’s Home Page by an Account Admin before it is visible.

If you have this option on your Home Page, you are able to click and access the webcast on the **Start Date** and **Time** of the event to access it.  If you attempt to access the event before the Start Date and Time, you will be placed in a Lobby (if enabled) or on the Webcast Settings page until the Event Host begins broadcasting.

</Image>

## Join From the Event Calendar

Navigate to [The Event Calendar](doc:the-event-calendar) on the **Start Date** and **Time** and access the event.  Keep in mind that not all webcasts are accessible to everyone. If you attempt to access the event before the Start Date and Time, you will be placed in a Lobby (if enabled) or on the Webcast Settings page until the Event Host begins broadcasting.

<Image title="eventCalendar.png" alt={962} src="https://files.readme.io/ae14bcc-eventCalendar.png">
  The event calendar displays the various scheduled events in Rev.  You are able to see those visible to you based on your role and permissions.
</Image>

## Join From a URL Invite as a Licensed User

Your Event Host or Moderator may also send you an event invite through an email or calendar invite. Clicking the provided **URL** will prompt you to log in to Rev where you will then be redirected to the webcast. If you attempt to access the event before the Start Date and Time, you will be placed in a Lobby (if enabled) or on the Webcast Settings page until the Event Host begins broadcasting.

## What Happens When You Join a Webcast

You automatically join the webcast if the Event Host has started broadcasting. If the webcast has started but is not yet broadcasting, you are placed in the event **Lobby** on [The Webcast Landing Page](doc:the-webcast-landing-page) to wait until broadcasting begins.

If the Event Host has not yet started the webcast or Lobby, event details are displayed instead. You are then automatically added to the Lobby once it starts or broadcasting begins by the Event Host.

> 👍 Tip
>
> **Private** events (denoted by a Lock icon) are only displayed when the following conditions are met:
>
> * You are an Event Admin or Account Admin or the Event Host that created the event.
> * You have been invited to the Private event.
> * A **Group** you belong to is invited to the event. If you are subsequently removed from that Group, you no longer are able to view or attend the event.

## Accessing a Webcast Recording After the Event

If the webcast you attend is recorded, it is normally made available once the event concludes.  You may access it through the same URL you used to attend the event.

* Click the URL in the email you received when you registered for the event or added it to your calendar
* Navigate to [The Event Calendar](doc:the-event-calendar) and click the **Webcast Recording** URL
