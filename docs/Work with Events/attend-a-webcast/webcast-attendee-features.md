**Attendee Engagement** features that have been set up for the webcast are accessed on the right navigation flyout panels.  Clicking an icon displays what is currently configured (and active) for the event.  If the following icons are not visible, this means they have not been activated for your specific webcast.

## Submit a Chat Comment

The **Chat **icon is used to chat with other people attending the webcast.

[block:image]
{

    {

        600
      ],
      "align": "center",
      "caption": "Chat is more informal than Q&A, is not moderated, and may not be used anonymously"
    }
  ]
}
[/block]

- You may only submit comments for webcasts that have been started
- You may view comments that have been submitted prior to when you joined the webcast
- Comments are displayed in the order they are submitted
- You can _not_ submit an anonymous comment. If you want to ask an anonymous question, use the Q&A interface instead (if enabled).
- When new comments are available, the Chat icon displays a visible indicator

## Answer a Poll

You can answer a poll that has been opened by the Event Host by clicking the **Poll **icon.  All Polls that have been opened will then display.  If more than one poll is available it is indicated in text and the number of dots at the top of the tab. Use the back and next arrows for paging between open polls or click a dot.

- Some polls may allow you to select more than one answer. This is indicated by square selection checkboxes as opposed to round radials when only one selection may be made.
- Your answers are not submitted until you click the **Submit **button
- You may select and/or change your answer so long as the poll remains open even after you have submitted an answer. Click an answer again and the **Submit **button becomes active again. Once the poll is closed, however, you may not submit it again.
- When a new poll opens, the poll icon displays a visual reference indicating this
- Once a poll has been published by the Event Host, it displays in the tab with the results.  You may select how you view those results by selecting a poll type.  You are also able to switch back and forth between the two.
  - bar chart - displays the percentages selected for an answer in bar form
  - donut - displays the percentages selected in a colored donut

## Submit a Question

The **Q&A** icon is used to submit questions to the Event Moderators so that specific topics can be discussed during a webcast. Questions that you submit are answered and visible to you under the **My Questions** tab. 

Click the **Post Anonymously** checkbox if you do _not_ want your Username displayed with the question.

[block:image]
{
  "images": [
    {
      "image": [

[/block]

- Other attendees are _not_ able to see the questions that you submit unless the Event Host or Moderator decides to make the question public (and therefore visible) to all attendees. 
- If the question is made public (visible), it is moved to the **Group Questions** tab.  A question that is made public is also made **anonymous **regardless of how it was submitted.

> 👍 Tip
> 
> Check the **Group Questions** tab before you submit a question to make sure it has not already been asked and answered.

Rev tracks the status of your question and keeps it updated in real-time, including any action taken on it by event staff.

## View Webcast Details

View relevant webcast details by clicking the **Event Details** icon. _Keep in mind that some of these features must be enabled by the Event Host during the event setup before they appear here_.

[block:image]
{
  "images": [
    {
      "image": [
        "https://files.readme.io/b29e46c-attendeeEventDetails.png",
        "attendeeEventDetails.png",
        352
      ],
      "align": "center",
      "caption": "Event Details that are enabled by the Event Host are viewable here"
    }
  ]
}
[/block]

This section displays the following information (when enabled/relevant):

- Event Title
- Start and End Date/Time
- Event Description
- Event URL
- Password
- PowerPoint Download Link

## View a Webcast Recording

Recorded Webcasts are found under the [Media](doc:user-menu-options) menu along with other videos. However, the **Slide **icon may be used to skip to specific areas of the recorded Webcast if desired.
