The **Webcast Landing Page** is displayed when an event is clicked with details about the **Main Event** and/or any **Pre-Production Events** that are scheduled.   How long this page is accessible before the webcast starts depends on how much [Lobby Time](doc:event-basic-settings#lobby-time) is allotted during event set up.

If an attendee is invited to a **dry run** or** pre-production webcast **that is not yet broadcasting a pre-production banner is displayed at the top of the landing page, similar to the one below.

The Webcast Landing Page displays:
* Event Title
* Description
* Start Date/Time
* End Date/Time
