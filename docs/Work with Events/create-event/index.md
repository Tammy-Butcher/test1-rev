Rev **Admins** and **Event Hosts** create and host webcasts from the **Event Calendar**.

> 👍 Tip
>
> Event functions are dictated by [roles and permissions](doc:roles-and-permissions#section-events).

The **Listing Type** of an event determines who has access to the webcast and how visible it is in the Rev portal.  The Listing Type is generally one of the first determinations that is made when you create an event because several settings that are used or applied are also determined by its type.

The general **workflow** to create and manage a Rev webcast is:

1. Determine the the type of webcast you want to produce.  Event types include:
   * [Public Events](doc:public-events) - Anyone can register and attend that has the URL to the webcast and attendees are not required to log-in to Rev first.  You can set up a password and public registration fields as needed.
   * [Private Events](doc:private-events) - Only invited Rev users and groups may attend the webcast.
   * [All Users Events](doc:all-users-events) - All licensed Rev users in your portal may attend the webcast, once logged in.

2. Set the [Event Basic Settings](doc:event-basic-settings) that are the metadata for a webcast and that make it easier for your attendees to find and view the webcast.

3. Select a [Video Source](doc:video-sources) for your webcast to determine where it receives video from to broadcast to your attendees.  If recording, set the [Webcast Recording](doc:webcast-recordings) parameters that determines what happens to the video recordings once your webcast concludes.

4. Determine [Hosts and Moderators](doc:hosts-and-moderators) for your event and decide if it needs both types of roles involved (often based on attendee engagement components that you add).

5. Set the **Listing Type** of the event you determined in step one and add other attendee features based on that type in the [Attendees](doc:attendees) section.

6. Add the engagement features you want in your webcast such as **polls**, **chat**, and so forth and set them up in the [Attendee Engagement](doc:attendee-engagement) section.

7. Use [Event Branding](doc:event-branding) (if desired) to modify the look and feel of the webcast.

8. You are now ready to [Prepare a Dry Run](doc:prepare-a-dry-run) to test the event and/or [Host a Production Webcast](doc:host-a-production-webcast).

9. Use the [Webcast Settings Dashboard](doc:webcast-settings-dashboard) to manage your settings, invitations, registrations, and retrieve reports when the webcast concludes.
