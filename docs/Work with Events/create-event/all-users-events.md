When you want only licensed Rev user accounts to be able to join your event,  set the **Listing Type** to **All Users** in the [Attendees](doc:attendees) section.  This means that attendees _must_ log in and authenticate with Rev before they may attend.

The event also appears in the [Event Calendar](doc:the-event-calendar) and on the **Upcoming Events** carousel (unless it is unlisted).
