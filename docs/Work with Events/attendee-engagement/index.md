**Attendee Engagement** features add interactivity to Rev webcasts that keep attendees active and alert when attending an event instead of just passively watching a video or presentation.  This includes items that solicit feedback such as polls and question and answer features along with functions that convey information such as presentation files and background images.  

Once these features are enabled, you actively [control them](doc:controlling-attendee-engagement) as needed while hosting a webcast.

> 👍 Tip
>
> **Attendee Engagement** features need to be made *globally* available by Account Admins to make them visible for use during event set up.  Contact your Account Admin if you do not see a feature you want to add to your event.
>
> **View**: [Allow Webcast Features](doc:allow-webcast-features) in **Media Settings**
