You may want to display or send additional information to your attendees either during your event or once it is over.  This is possible with Rev webcasts by manually 'pushing' a website banner to attendees during the Live event or by setting your banner it to display automatically once an event has ended.

To create a Live event banner:

During event set up, set the **Banners** toggle to enabled.

Once you enable the feature, click the **Add Banner** button and you can add a new banner that will display to attendees either during or after the event depending on the **Push Method** you specify.

- **Name**: This is a descriptive name for the banner for your purposes; attendees do not see this.
- **Message**: A banner that overlays the live webcast; attendees can view and close this. 
- **Link / URL**:  This is a website that will open in a separate tab if configured and subsequently clicked by attendees during the webcast.
- **Push Method**: This defines how the banner will be pushed.
  - **Manual**:  The Event Host or Moderator will "push" the link manually at some point during live wdoebcast.
  - **At End**:  The banner displays automatically at the end of the webcast.

Once you have added your banners, you can edit, delete, and preview URLs in event settings.  Notice that you are also able to visually see the **Push Method** at a glance by noting the icon next to the link.  For example, a clock icon indicates this push link occurs once the event is concluded (At End).

Once the webcast begins, use the **Banners** icon and flyout panel to manage your banners and to manually [activate and add new banners](doc:manage-webcast-links) during your webcasts.
