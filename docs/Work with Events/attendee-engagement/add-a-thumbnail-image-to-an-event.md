You can add a thumbnail image to your webcast that is then displayed on the Home page **Upcoming Events** carousel.

<Image align="center" alt={700} border={false} caption="Event thumbnails are displayed on your portal Home page carousels" title="backgroundImage.png" src="https://files.readme.io/a328dff-eventThumbnail.png" />

To add an image as a thumbnail for your event:

1. Navigate to the event and scroll to the **Attendee Engagements** section.
2. Select the image you want to use next to **Event Thumbnail**.
   1. A [supported file type](doc:supported-file-types)  must be used
   2. Use an image that is a 16:9 aspect ratio. It will be displayed at 252 pixels.

<Image align="center" alt="Use an image that has a 16:9 aspect ratio" border={false} caption="Use an image that has a 16:9 aspect ratio" src="https://files.readme.io/88c8bbb-uploadEventThumbnail.png" />

3. When the event saved, the image is used as the thumbnail image on the carousel.
4. Keep in mind that if you do not upload your own thumbnail image, an icon is used instead. The [ background image](doc:add-a-background-image-to-a-webcast) is not used.

<Image align="center" alt="An icon is used as the thumbnail if you do not use your own image" border={false} caption="An icon is used as the thumbnail if you do not use your own image" src="https://files.readme.io/57f8ce8-eventThumbnailIcon.png" />
