A **Chat** interface may be enabled for your event if you want to allow your attendees to be able to comment to each other during the webcast. This interface is not the same as the Q\&A feature and should *not* be used to ask questions.

<Image title="enableChat.png" alt={540} align="center" src="https://files.readme.io/1b5a054-enableChat.png">
  The chat interface is not moderated
</Image>

* The chat interface is not moderated
* All comments made in the chat interface are associated to a user and are unable to be made anonymously
