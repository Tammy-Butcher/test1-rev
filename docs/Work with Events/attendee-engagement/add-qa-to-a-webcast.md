A **Q\&A** interface may be enabled for your event if you want to allow your attendees to be able to ask questions during your webcast. This interface is not the same as the Chat interface and should *not* be used for general comments and conversation among attendees.

<Image title="enableQA.png" alt={839} src="https://files.readme.io/127b79a-enableQA.png">
  The Q\&A feature is used for moderated question and answer sessions during an event
</Image>

A Q\&A session for your event provides the following features:

* Moderated question queues - As questions are asked by attendees, Event Admins or Event Moderators categorize them into one of three queues. Each question is handled from receipt until closure for the event speaker.
* When the event concludes, the Event Host or Event Moderator may view a Q\&A report for details on how each question was handled
* You may also specify if attendees are able to submit questions anonymously or if they *must* submit them anonymously
