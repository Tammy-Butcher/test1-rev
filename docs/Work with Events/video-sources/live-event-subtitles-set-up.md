You may transcribe Live subtitles for your webcast events and translate the [source language](doc:supported-languages#live-event-subtitles) by enabling the **Live Event Subtitles** tab. 

Requirements:

* [Rev IQ Transcription and Translation](doc:rev-iq-transcription-and-translation) integration enabled and Rev IQ credits available
* Available for all Rev sources, outside of 3rd party HLS
* Encoder-sourced webcasts require a [Rev IQ-enabled Presentation Profile](doc:add-a-presentation-profile#rev-iq-enabled-presentation-profiles) as a video source for encoder-sourced streams.

<Image title="liveSubtitlesEnabled.png" alt={1141} src="https://files.readme.io/7bb2b3b-liveSubtitlesEnabled.png">
  If you use a VC or Rev IQ presentation profile based video source and have Rev IQ Transcription and Translation enabled, you are able to use Live Event Subtitles with your webcasts
</Image>

When Live Subtitles are enabled:

* A **Source Language** dropdown appears. Languages available for transcription are English-US, English-GB, Spanish, French, French-Canadian, German, Italian, and Australian-English. This should be the language spoken in the webcast.
* You may enter the same languages for translation as used for VOD videos.
* There is a max of 8 languages for live subtitles
