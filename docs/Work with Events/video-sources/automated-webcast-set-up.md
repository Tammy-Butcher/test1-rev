The **Automated Webcast** setting makes it possible to schedule an event that begins broadcasting at the appointed start date and time on its own, automatically, without the need for the Event Host to start it.

[block:callout]

  "title": "Tip",
  "body": "Automated Webcast functionality is available for all Video Sources (MS Teams, Presentation Profiles, RTMP(S), Video Address, Webex Meeting Stream, Webex Teams, Zoom, and Existing Video) except Webcam and Screenshare."
}
[/block]
When a Webcast event is automated:

* The webcast is automatically started 5 minutes before the **Start** time, which allows attendees and hosts to join. 
* The webcast automatically begins broadcasting at the designated Start time, which means the attendees can see and hear the hosts.  Any applicable recordings also start and end automatically.
* Once the webcast begins, an Event Host may join and view and interact with any user engagements that have been enabled (presentations, polls, comments, etc.)
* Event and Account Admins are always able to see, edit, and join automated events through the event calendar and carousel just as they would a manual webcast
[block:callout]
{
  "type": "warning",
  "title": "Important!",
  "body": "If the webcast has *not* started, an Admin may always switch the event back to manual (non-automated) status for control by disabling the automated flag.  Once the webcast *begins*, including Lobby time, only the webcast controls may be modified.  No other webcast settings may be changed at that point."
}
[/block]
