A **Presentation Profile** is used to define a device profile for your event and specifies attributes such as video sources set up by Admins, including the device streams needed to hold Live streams. Profiles that contain [Custom Devices](doc:add-a-source-or-custom-device) cannot use the same source URL within concurrent events.  You cannot use the same URL (within Custom Devices) as a source to two (or more) concurrent events.  You must select a device to stream your video for each Live event.

<Image title="presentationProfiles.png" alt={536} align="center" src="https://files.readme.io/3e21224-presentationProfiles.png">
  An Account Admin normally creates device (presentation) profiles that contain video sources and destination streams for events
</Image>

Use the **Available** button to view only the profiles that are available for the indicated date/time you have scheduled for your event.  You may not "double-book" a profile.

Click the **Calendar** icon in the **Schedule** column to view the events that have been scheduled for the presentation profile (both past and future). **Event Names**, **Start** and **End** date and times, and **Event Admin** are listed.

<Image title="presentationProfileSchedule.png" alt={527} align="center" src="https://files.readme.io/55a9459-presentationProfileSchedule.png">
  The Calendar icon next to the profile presents the schedule for it with relevant details
</Image>

Click the **Choose** button to use the Presentation Profile for your event if it is available.
