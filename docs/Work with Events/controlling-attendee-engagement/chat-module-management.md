The **Chat** interface can be enabled for a webcast if you want to allow your attendees to be able to comment to each other during the event. This interface is *not* the same as the Q\&A module and is not generally used to ask questions.

<Image title="chatModule.png" alt={352} align="center" src="https://files.readme.io/cc0f2434b6feea0b777d748703df36521874cc28279a9ac7e33829dc5abeff44-chatInterface.png">
  The Chat module may only be lightly moderated by Event Hosts or Event Moderators
</Image>

Keep in mind:

* The Chat interface is only lightly moderated with the ability to hide comments and mute users by clicking the 3 dot menu next to their comment(s).  

<Image align="center" src="https://files.readme.io/0b2227d33556f267dfeba117944e80734c3098d61fa0832239d0bb00337c3e49-moderateChatuser.png" />

* For more detailed moderation, with question and answer scenarios such as a panel session for example, the [Q\&A module](doc:qa-module-management) should be used instead.
* All comments made in the Chat interface are associated with a user account and cannot be made anonymously.

<Image align="center" src="https://files.readme.io/9708a495d9e36d15b871b078f4f0844e7cea6fea7f79a7f97db63ca09da23851-chatModeration.png" />

* The Chat user is notified if one of their comments are hidden (or if they are muted).
* This is also reported in the [Chat Log report](doc:download-a-webcast-chat-log-report) once the event has concluded.
