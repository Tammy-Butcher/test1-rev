The **Chat **interface is enabled for a webcast if you want to allow your attendees to be able to comment to each other during the event. This interface is not the same as the Q&A module and should not be used to ask questions.

Keep in mind:

- The chat interface is not moderated. Use the Q&A module for moderated questions.
- All comments made in the Chat interface are associated with a user account and cannot be made anonymously.
