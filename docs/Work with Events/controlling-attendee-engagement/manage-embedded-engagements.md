Event Hosts and Event Moderators may display and manage third-party embedded content that has been added during [event set up](doc:allow-webcast-engagement-embeds) through the **Embedded Content** icon. 

Clicking this icon displays the **Embedded Content** flyout which allows you to *activate* the engagement using the toggle next to it which means it will be viewable to attendees.

<Image title="manageEmbeddedContent.png" alt={552} align="center" src="https://files.readme.io/4ba160b-manageEmbeddedContent.png">
  The Embedded Content icon displays all third-party embeds that have been added to a webcast
</Image>

> 👍 Tip
>
> Clicking the **Manage Embedded Engagements** icon also provides access to edit, delete, and the ability to add new third-party engagements as needed to the webcast. You are able to do this after the event begins without the need to leave the webcast.

## Activating an Embedded Engagement

When you activate an [embedded engagement](doc:embed-a-webcast-attendee-engagement), the icon you assigned to it during the event setup appears under the **Manage Embedded Engagement** icon. Each subsequent engagement activation icon (up to five) appears under the previous activation icon.

<Image title="activateEngagement.png" alt={554} align="center" src="https://files.readme.io/97941bf-activateEngagement.png">
  Activating an embedded engagement makes its icon and tab visible (created during set up)
</Image>

> 🚧 Important!
>
> Keep in mind that this also activates it on your Attendee's view as well.  So be prepared to start sharing on your engagement's back-end (if applicable) when you activate it on the webcast.

Once you activate your engagement, whatever you "push" on the engagement's back-end is now presented on the embedded engagement tab that is displayed.

<Image title="joinQuiz.png" alt={553} align="center" src="https://files.readme.io/458e8bf-joinQuiz.png">
  Attendees are able to interact with your engagements directly through the Rev tab
</Image>

Attendees are able to directly see what is present on the URL you have activated, whether it is you presenting something, or something for attendees to view or interact with, without the need to switch screens or browser windows or leave the Rev portal at all.
