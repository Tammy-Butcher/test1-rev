If you have a large event with hundreds or even thousands of attendees, you may find that attendee reactions and emojis flooding the viewing area is overwhelming or disruptive. Or, you may decide that you want to provide different reactions instead of the emojis that were enabled during event set up.

While each individual attendee is able to hide reactions on their own viewing screen through the **Reactions** icon, the Event Host or Moderator can always disable them for the entire event at any time by editing event settings just as you would any other setting [during an ongoing Live webcast](doc:edit-settings-during-an-ongoing-webcast) with the **Edit Settings** button.
