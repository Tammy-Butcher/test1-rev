Event Hosts and Event Moderators can manage and push the webcast banners that have been added during [event set up](doc:add-links-to-a-webcast) through the **Banners** icon and flyout panel. 

Clicking this icon displays the **Banners** flyout which allows you to _activate_ the _manual_ webcast banners that were set up using the toggles next to them.  When enabled, all event attendees will see the messages and URLs created overlaid on the upper right side of their video player window.

In addition to the banners that were added to the webcast that can be toggled (shown) on/off manually, the at-end timed links that are set to appear once the webcast has concluded are also displayed with a clock icon next to them.

> 👍 Tip
> 
> If needed, an Event Host can click the **New Banner** link and create a webcast banner on-the-fly during a live event. You can also edit and delete banners after the event begins without the need to exit the webast.

## Activating a Live Event Banner

To activate a manual [webcast banner](doc:add-links-to-a-webcast) that was added during event setup, click the toggle next to it on the **Banners** flyout.

[block:image]
{
  "images": [
    {
      "image": [
        "https://files.readme.io/6c96755-activateManual.png",
        "activateManualLink.png",
        "Activating a manual Banner overlays it on the webcast video and/or presentation display"
      ],
      "align": "center",
      "caption": "Activating a manual Banner overlays it on the webcast video and/or presentation display"
    }
  ]
}
[/block]


When you activate a manual webcast banner it is overlaid on the Live webcast video broadcast window and all Attendees as well as the Event Host and Moderators can view it. It can be closed by clicking the X in the upper right corner and URLs (if included in the message window during set up) can also be clicked and opened in a separate window.

  ]

> 🚧 Important!
> 
> An active banner may not be edited or deleted.  You must toggle it off before you may edit it.

## Webcast Banners Set to Display At-End

Any banners that were added during event setup that were set to show At End, will always appear automatically at the end of the webcast in a pop-up window.  Attendees then have the option of closing the pop-up or simply leaving the event without clicking any of the links.
