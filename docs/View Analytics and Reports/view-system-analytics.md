The **Account Admin Dashboard** displays when the Gear icon is clicked and Admin functions are accessed (or when the **Reports **option is selected from [Admin Menu Options](doc:admin-menu-options)). This dashboard displays _account-wide_ system analytics related to video views, webcast events, user accounts, and Rev usage metrics. It may be viewed by both Account and Media Admin roles.

Use the **Date Range** control to filter your views for by Days, Months, Year, or enter a custom \\ range in the picker. Note that this control changes _all_ system analytics on the dashboard charts and graphs by the view you select.
