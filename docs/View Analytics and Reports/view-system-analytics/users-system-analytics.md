The **Users** tab on the Account Admin Dashboard details user account stats and device usage in the portal. The **Users** tab displays the following data:

* Active Users (Last 30 Days)
* Total number of licensed users

<Image title="monthlyActiveUsersKPI.png" alt={1759} src="https://files.readme.io/c1225b3-monthlyActiveUsersKPI.png">
  Track your monthly active users and total licensed users with the Users tab if you have a Monthly Active Users license type
</Image>

**Daily Active User** totals by day (rolling over a specific day includes the daily total).

<Image title="dailyActiveUsers.png" alt={1747} src="https://files.readme.io/74692eb-dailyActiveUsers.png">
  The daily active users tells you how frequently each day your portal is being accessed
</Image>

## Device Analytics for User and Active User Type Licensing

**Device** stats, such as logins by browser and logins by device, are displayed for both user license types.

  Device stats by User
