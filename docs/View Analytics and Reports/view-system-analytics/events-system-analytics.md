The **Events** tab on the Account Admin Dashboard details attendee and live event duration trends for all of the events in the portal based on the Date Range you select.

Four summary metrics provide a quick view of webcast statistics:

* Events (Count)
* Unique Attendees
* Total Duration
* Average Duration (Total Duration divided by the Live Event Count)

<Image title="systemEventsKPIS.png" alt={1775} src="https://files.readme.io/642fc34-systemEventsKPIS.png">
  Events Key Performance Indicators are displayed based on a Date Range you select
</Image>

## Active Live Events Analytics

The **Active Live Events** chart displays all **Production** events that are currently ongoing when you access the Events tab.  If there are no ongoing events, this chart is not displayed.  Pre-production webcasts are not displayed.

<Image title="activeLiveEvents.png" alt={1202} src="https://files.readme.io/0e0f27f-activeLiveEvents.png">
  This chart displays all ongoing Webcasts in the portal (if applicable).  You can search the table if you do not immediately see the event you are looking for.
</Image>

> 📘 Note
>
> Only ten events are displayed at any one time.  If more than ten events are ongoing, you can search for an event.

## Attendees

The **Attendees** chart displays the total attendance of Live events across the portal.  Note that this is for those webcasts that have not been deleted from Rev.  In other words, deleted data is not accounted for in this analytic.

<Image title="attendees.png" alt={1200} src="https://files.readme.io/5371105-attendees.png">
  The total attendance of Live events across the portal
</Image>

For ranges of \< 90 days, the x-axis interval is by day.  For ranges of > 90 days, the x-axis interval is 7 days.  The chart begins when the first event occurs in a date range.  Mouse over a bar to display the attendee count for that time period.

## Export an Events System Analytics Report

Use the system-wide **Events** table to view event metrics by the **Date Range** you select. A sorting and filtering **Columns** control allows you to filter additional key metrics that you specifically want to observe without the need to download the report(s) first.

<Image title="eventsAnalyticsReportExport.png" alt={1202} src="https://files.readme.io/dd2552e-eventsAnalyticsReportExport.png">
  Use the Events table to view key metrics across events.  Fields denoted with an asterisk are searchable.
</Image>

Default fields selected include:

* Scheduled Start Date
* Event Title
* Attendees
* Experienced Rebuffing (%)
* Average Experienced Rebuffer Duration
* Experienced Errors/Attendees

You can choose to download any report you set up by clicking the **CSV** button.
