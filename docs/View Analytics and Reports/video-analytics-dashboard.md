Each video in Rev contains a **Video Analytic Dashboard** that is accessed from the [Video Player](doc:rev-video-player-features#video-reports) by clicking the **Reports **icon. Each report dashboard provides detailed analytics for that specific video.

The following analytics are observed on the Video Analytic Dashboard:

- Total Views (since upload)
- Unique Viewers (includes anonymous views)
- Completion Rate (%)
- Average Viewing Time

The **Date Range** control filters your view by Day, Month, and Year, or you can enter a custom range in the picker. Note that this control changes \_all \_analytics on the video dashboard by the range you select.

A sorting and filtering **Columns **control allows you to filter the key metrics that you specifically want to observe about the video without the need to download the report first. Note you may still download the complete report should you so choose.
